# ZeroAllocPrimitives ⚡ (WIP)

**High-Performance C# Primitives & Tricks**

A curated collection of specialized, zero-allocation C# data structures and utilities designed for high-frequency systems.

These modules were extracted and generalized from a real-world High-Frequency Trading (HFT) system. They are provided here as independent, bite-sized code samples to act as a "cookbook" of senior-level C# techniques, demonstrating deep understanding of memory management, lock-free threading, and the CLR.
